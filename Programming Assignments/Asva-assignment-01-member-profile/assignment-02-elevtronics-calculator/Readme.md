# Assignment 02: Basic Electronics Calculator

## Description
This C++ program is a basic electronics calculator built for the ASVA Hardware Club. It collects voltage and resistance values from the user, then uses Ohm's Law and the electrical power formula to calculate the resulting current and power.

## Topics Applied
* **C++ User Input:** Used `cin` to collect numerical data and `getline()` to collect string data with spaces.
* **C++ Data Types:** Used `std::string` for the user's name and `double` for electrical values to accurately handle decimal results.
* **C++ Operators:** Applied the division (`/`) operator to calculate Current and the multiplication (`*`) operator to calculate Power.
* **C++ Strings:** Handled textual data to dynamically greet the user in the final output.

## How to Run
1. Compile the code using a C++ compiler: `g++ calculator.cpp -o calculator`
2. Run the executable file in your terminal.
3. Follow the on-screen prompts to input your name and circuit values.
